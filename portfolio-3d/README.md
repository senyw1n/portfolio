# Sayat Zhaksybay — 3D-портфолио

React + Three.js (React Three Fiber). Сайт — одна 3D-сцена: камера перелетает между объектами-разделами.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. В VS Code сайт запускается сам при открытии папки
(задача «Запустить сайт»; или `Ctrl+Shift+B`). `F5` — открыть сайт в браузере.

## Где что править

- `src/data.js` — весь текст: проекты, навыки, опыт, контакты.
- `src/scene/Stations.jsx` — 3D-объекты каждого раздела.
- `src/ui/Overlay.jsx` — текстовые панели, меню, строка состояния.
- `src/styles.css` — оформление.

## Сборка для публикации

```bash
npm run build
```

Готовый сайт — в папке `dist/`.
